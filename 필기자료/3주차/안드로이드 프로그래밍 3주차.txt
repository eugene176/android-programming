텍스트뷰
text = 문자열 표현(내용물)
text_color = RRGGBB AARRGGBB로 문자 색깔
text size = 글자 사이즈
typeface = 
textstyle = 글꼴 지정(글꼴체 이름이 인수)

------레이아웃 옵션-----
padding(좌우에 여백을 주는 것,레이아웃에 사용)
android:padding="30dp"

layout_margin(글자간의 간격을 주는 거)

visibility 속성
ndroid:visibility="visible" 
ndroid:visibility="invisible" 
ndroid:visibility="gone" 
visible = 눈에 보임
invisible = 눈에 안보임(자리는 차지)
gone = 사라짐

enabled,clickable 속성
enable = 위젯동작여부(홀수면 불가+회색으로 나옴)
clickable = 클릭 여부

rotation(기울기) 속성
android:rotation="각도"

gravity = 내용물을 어느 방향에 붙혀라
layout_gravity = 레이아웃을 어디에 붙혀라
인수 : center(중앙)/left(왼쪽)/right(오른쪽)/start(layout시작부분 or 화면 시작부분)/top(위쪽)/bottom(아래쪽)/end(마지막 부분)
